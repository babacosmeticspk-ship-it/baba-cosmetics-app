# Baba Cosmetics — Android App

یہ بابا کاسمیٹکس کی اینڈرائیڈ ایپ کا مکمل کوڈ ہے۔ ایپ سیدھی www.babacosmetics.com (Shopify اسٹور) سے لائیو ڈیٹا اٹھاتی ہے۔

## ایپ میں کیا کیا ہے
- **ہوم:** لوگو، سرچ، ویب سائٹ والے بینرز کا سلائیڈر (خود چلتا ہے، ٹیپ کرنے پر پروڈکٹ/کیٹیگری کھلتی ہے)، کیٹیگریز، پروموشن پوسٹرز، اور تمام پروڈکٹس
- **کیٹیگریز:** ویب سائٹ کے مینیو والی ساری کیٹیگریز (Bundles، Serums، Bleach، Face Wash وغیرہ)
- **پروڈکٹ پیج:** تمام تصاویر، قیمت، پرانی قیمت، ڈسکاؤنٹ %، سائز/آپشن، تعداد، تفصیل، شیئر بٹن
- **کارٹ:** پروڈکٹ ایڈ/کم/ڈیلیٹ، ٹوٹل، اور "Rs. 3,000 سے اوپر فری ڈیلیوری" کا میسج
- **چیک آؤٹ / Buy Now:** آرڈر Shopify کے اصلی چیک آؤٹ سے ہوتا ہے (COD سمیت جو بھی پیمنٹ آپ کے اسٹور پر آن ہے)۔ آرڈر سیدھا آپ کے Shopify Admin میں آتا ہے۔
- **اکاؤنٹ:** کسٹمر اپنا لاگ اِن اور آرڈرز دیکھ سکتا ہے

نئی پروڈکٹ، قیمت یا تصویر Shopify میں بدلیں تو ایپ میں خود بخود بدل جائے گی — ایپ دوبارہ بنانے کی ضرورت نہیں۔
صرف **بینرز اور کیٹیگریز کی لسٹ** فائل `app/src/main/java/com/babacosmetics/app/Config.java` میں ہے؛ انہیں بدلنا ہو تو وہاں بدل کر ایپ دوبارہ بنائیں۔

## APK کیسے بنائیں — طریقہ 1: GitHub (سب سے آسان، کمپیوٹر پر کچھ انسٹال نہیں)
1. github.com پر مفت اکاؤنٹ بنائیں۔
2. نیا Repository بنائیں (مثلاً `baba-cosmetics-app`)۔
3. "uploading an existing file" پر کلک کریں، اور اس زِپ کو کھول کر اس کے **اندر کی ساری فائلیں اور فولڈرز** (بشمول `.github` فولڈر) وہاں ڈریگ کر دیں، پھر **Commit changes** دبائیں۔
   - نوٹ: `.github` فولڈر کچھ کمپیوٹرز پر چھپا ہوتا ہے، اسے "Show hidden files" آن کر کے دیکھیں۔
4. اوپر **Actions** ٹیب کھولیں — "Build APK" خود چلنا شروع ہو جائے گا (5–8 منٹ)۔
5. ہرا نشان ✓ آنے پر اسے کھولیں، نیچے **Artifacts** میں `BabaCosmetics-APK` ڈاؤن لوڈ کریں۔ زِپ کے اندر `app-debug.apk` ہے — اسے فون پر بھیج کر انسٹال کریں (فون "Unknown apps" کی اجازت مانگے گا، اجازت دے دیں)۔

## طریقہ 2: Android Studio
1. Android Studio انسٹال کریں (developer.android.com/studio)۔
2. **Open** کر کے یہ فولڈر کھولیں، Gradle sync ہونے دیں۔
3. مینیو: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**۔

## Play Store پر لگانے کے لیے
Play Store کے لیے "signed release" بنانا پڑتا ہے (Android Studio میں **Build → Generate Signed App Bundle**)، اور Google Play Developer اکاؤنٹ ($25 ایک بار)۔ آئیکن کے لیے `playstore-icon-512.png` تیار ہے۔

## تکنیکی معلومات
- زبان: Java، کوئی بیرونی لائبریری نہیں
- Android 6.0 (API 23) اور اس سے نئے تمام فونز
- Package name: `com.babacosmetics.app`
